AI対戦モードのAPIキーはブラウザには置かず、サーバーの環境変数で管理します（Vercel の Project → Settings → Environment Variables）。
・GRAME_API_KEY（必須）：Groq などの OpenAI 互換 API キー。Groq は groq.com のコンソールで無料発行でき、無料枠の目安は1日1,000リクエスト／200Kトークン（このゲームなら1日25試合以上）。
・GRAME_API_BASE（任意）：既定は Groq のエンドポイント。
・GRAME_MODEL（任意）：既定は qwen/qwen3.8-27b。
環境変数を設定したら Vercel で再デプロイすると有効になります。未設定の間は文法モード（CSV辞書＋文法ルールで判定するオフライン対戦）で動作します。
