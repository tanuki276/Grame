# 造句対戦（Grame）

AIと交互に中国語の単語を1つずつ追加して文を作る、対戦ゲーム（Web版）。

## ルール

- プレイヤーとAIが交互に **1単語** を文の末尾に追加する
- 追加した単語で **文法・意味が破綻したら、破綻させた側の負け**
- 文を完成させて、相手が自然に続けられなくなったら **完成させた側の勝ち**
- 例：我 → 是 → 学生 → 的 → 老师
- 例：我 → 昨天 → 在 → 学校 → 吃 → 苹果 → 了
- 例：他 → 比 → 我 → 更 → 聪明

## ファイル構成

- `index.html`: ゲームUI（和紙×朱印デザイン、ライト／ダーク対応、IME安全入力、候補アシスト、辞書モーダル、戦績保存）
- `grame-engine.js`: NFA有限状態文法エンジン（意味クラス・程度副詞制約・介詞サブクラス・否定「不/没/没有」規則・節単位の主語有生性チェック・タグ索引付きAI手選択）
- `lexicon.csv`: 品詞・意味タグ付きの中国語辞書（約385語）。HTTP配信時は `index.html` から直接読み込まれる
- `api/chat.js`: AI対戦モード用の Vercel サーバーレスプロキシ（`<think>`タグ除去・タイムアウト・エラー処理対応）

## モード

- **文法モード（オフライン・キー不要）**：`lexicon.csv` と `grame-engine.js` の文法・意味ルールで判定する対戦モード。入力候補ヒントのON/OFF切り替えや辞書ブラウザからのタップ入力にも対応。
- **AI対戦モード**：Vercel の環境変数にAPIキーを設定すると有効になり、画面上から文法モードとの切り替えも可能。
  - `GRAME_API_KEY`（必須）：Groq などの OpenAI 互換 API キー
  - `GRAME_API_BASE`（任意）：既定 `https://api.groq.com/openai/v1`
  - `GRAME_MODEL`（任意）：既定 `qwen/qwen3.8-27b`
