# 造句対戦（cn-sentence-battle）

AIと交互に中国語の単語を1つずつ追加して文を作る、対戦ゲーム。

## ルール

- プレイヤーとAIが交互に **1単語** を文の末尾に追加する
- 追加した単語で **文法が破綻したら、破綻させた側の負け**
- 文を完成させて、相手が自然に続けられなくなったら **完成させた側の勝ち**
- 例：我 → 是 → 学生 → 的 → …（「我是学生的…」と育てていく）

## 遊び方

`index.html` をブラウザで開くだけ。GitHub Pages を有効にすればURLでも遊べる
（Settings → Pages → Branch: main / root）。

### モード

- **簡易モード（キー不要）**：固定の例文データで判定する練習用AIと対戦。判定はコーパス内の文の途中かどうか。
- **AI対戦モード**：設定欄に OpenAI 互換 API のキーを入れると、相手の手も文法判定もLLMが担当する。
  - 推奨：DeepSeek（`https://api.deepseek.com` / `deepseek-flash`）など中国語が強いモデル
  - キーはブラウザの localStorage にのみ保存され、外部に送信されるのは設定したAPIエンドポイントだけ

## 技術

- 単一HTMLファイル（ビルド不要、依存なし）
- 判定プロンプト・AIの手生成プロンプトは `index.html` 内の `JUDGE_SYSTEM` / `MOVE_SYSTEM`
- 簡易モードのコーパスは `CORPUS` 配列。文を足せばそのまま対戦の幅が広がる
