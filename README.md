# 造句対戦（Grame）

AIと交互に中国語の単語を1つずつ追加して文を作る、対戦ゲーム。

## ルール

- プレイヤーとAIが交互に **1単語** を文の末尾に追加する
- 追加した単語で **文法が破綻したら、破綻させた側の負け**
- 文を完成させて、相手が自然に続けられなくなったら **完成させた側の勝ち**
- 例：我 → 是 → 学生 → 的 → …（「我是学生的…」と育てていく）

## 遊び方

`index.html` をブラウザで開くだけ。Vercel にデプロイ済み：
https://grame-blond.vercel.app/

### モード

- **文法モード（キー不要）**：内蔵辞書（約350語・品詞タグ付き）と文法ルール
  （有限状態の語順パターン）で判定するオフライン対戦。決まった例文には縛られず、
  辞書の語彙の範囲で自由に文を作れる。辞書に語を足せば語彙が増える。
  辞書にない語は「辞書外」として破綻扱いになる。
- **AI対戦モード**：設定欄でプロバイダのプリセットを選び、OpenAI 互換 API のキーを入れると、相手の手も文法判定もLLMが担当する。
  - プリセット：Groq（無料枠・Qwen3.8 27B、中国語に強い。既定）／ Gemini（無料枠）／ DeepSeek（有料・激安）／ カスタム
  - キーはブラウザの localStorage にのみ保存され、外部に送信されるのは設定したAPIエンドポイントだけ

## 技術

- 単一HTMLファイル（ビルド不要、依存なし）。UI は Material You（Material Design 3）× 中華風
- 文法エンジンは `index.html` 内の `<script id="grame-engine">`：
  語彙辞書 `LEXICON`（語→品詞タグ）と状態遷移 `TRANSITIONS` で、
  主語→（時間・副詞・介詞句）→述語→目的語 の語順と、的・了・語気助詞・節の接続を判定する
- AI対戦モードの判定／手生成プロンプトは `JUDGE_SYSTEM` / `MOVE_SYSTEM`
